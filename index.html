A to E

A practice MCQ bank for Australian medical students in their clinical years. An ever-increasing number of single-best-answer clinical-reasoning questions across paediatrics, obstetrics & gynaecology, psychiatry, and adult medicine, every option cited inline against a free Australian clinical reference so any claim is verifiable. Questions are calibrated to test the reasoning steps a candidate has to take, not solvable by spotting a keyword in the stem. Static frontend backed by a Cloudflare Worker; guest mode keeps progress on the device, signed-in users see how other users picked each option plus first-time accuracy and per-discipline stats. Authors paste new questions via a self-contained prompt that works in any free LLM (no API key required), audit and promote them through an in-app dashboard, or run a scheduled cloud agent that publishes fresh batches automatically.

Cloudflare Workers · D1 · GitHub Pages
mord58562.github.io/a-to-e ↗ (live, guest mode - no signup) github.com/mord58562/a-to-e ↗
Install

There are three ways to use A to E, ordered by how much setup you want to do.

Option 1 - Just use it (zero setup)

Open the live site above. Guest mode keeps your progress in your browser. Nothing to install.

Option 2 - Run the frontend locally (offline copy)

You get the full question bank, all keyboard shortcuts, the reference-values panel, and local progress. No accounts, no cross-device sync. Good for offline study.

Download source zip 
unzip a-to-e.zip && cd a-to-e
./scripts/start.sh             # serves http://127.0.0.1:8765/

Requires python3 (preinstalled on macOS and most Linux). Any modern browser.

Option 3 - Run your own worker (full self-host)

Adds accounts, cross-device sync, social stats (your bank only sees your own users), and automated batch publishing back to your fork of the repo. Free on Cloudflare's hobby tier for small numbers of users.

Prerequisites: a Cloudflare account, a GitHub fork of mord58562/a-to-e, and the wrangler CLI (brew install cloudflare-wrangler).

cd cloudflare-worker
npm install
wrangler login                                       # opens browser, one-off
wrangler d1 create a-to-e                            # copy database_id into wrangler.toml
wrangler d1 execute a-to-e --file=schema.sql --remote
wrangler d1 execute a-to-e --file=schema_002_encrypt.sql --remote

# Three secrets for PII encryption (generate any 32-byte values):
openssl rand -base64 32 | wrangler secret put EMAIL_HMAC_KEY
openssl rand -base64 32 | wrangler secret put EMAIL_ENC_KEY
openssl rand -base64 32 | wrangler secret put SESSION_PEPPER

# Two secrets for GitHub publishing (only if you want the in-app paste flow):
wrangler secret put GITHUB_TOKEN                     # fine-grained PAT, Contents R/W on your fork
wrangler secret put ROUTINE_TOKEN                    # any random string; gates /commit-batch

wrangler deploy

Wrangler prints your worker URL. Open assets/app.js, set WORKER_URL to that URL, commit and push to your fork. cloudflare-worker/DEPLOY.md walks through verification queries.

Uninstall (option 3 only): wrangler delete a-to-e-worker deletes the worker; wrangler d1 delete a-to-e deletes the database. For options 1 and 2 there is nothing to uninstall - close the tab or delete the folder.

What's new in 2.0.0: cloud accounts (email + password) sync progress across devices, guest mode stays local; admin accounts get a unified Overview / Add & Audit / Quality / Users / Account dashboard. Difficulty scale overhauled - L2 is the new floor, L3 / L4 dominate (~95%), L5 is a new extreme tier (~5%) requiring complex reasoning and possibly niche knowledge. Signed-in users see a social-stats panel showing what proportion of other users picked each option after submitting. Per-level difficulty toggles on the home screen. A scheduled cloud routine generates and self-audits fresh batches automatically.

Earshot

A menubar parametric EQ for macOS system audio, routed to any output device you pick. Up to 24 bands rendered as draggable dots on the frequency response - drag to set frequency and gain, Cmd-Z to undo. Live editing without dropouts. Auto-preamp parks peaks just under clipping and only ever attenuates. Save named EQ presets; import and export AutoEq ParametricEQ.txt, or search the built-in catalog of ~2000 oratory1990 and Crinacle measurements and load one as a preset. One-click speakers passthrough for when you yank headphones and don't want to dig through Sound preferences. Works with any 2-channel virtual loopback (BlackHole 2ch, VB-Cable, Soundflower, or Loopback Audio).

Install

Requirements: macOS 13 Ventura or later, Apple Silicon. Two paths.

Prebuilt (no Terminal): install a 2-channel loopback driver first - BlackHole 2ch is recommended (brew install blackhole-2ch or download from existential.audio/blackhole), but VB-Cable, Soundflower (2ch), or Loopback Audio also work. Then download Earshot.app.zip from the latest release, unzip, drag Earshot.app to /Applications. First launch: right-click Earshot.app → Open (the build is ad-hoc signed; this is the standard Gatekeeper override).

From source: install.sh handles everything - it checks for BlackHole 2ch, Homebrew-installs it if missing, builds the app, copies it to /Applications, and launches it.

Download source zip 
# one-time, skip if already installed
xcode-select --install

cd ~/Downloads/Earshot
# detects + installs BlackHole, builds, copies, launches
./install.sh

On first launch, approve the Microphone permission (macOS classifies virtual loopbacks as microphones). Earshot auto-registers as a login item. If you don't have Homebrew, install a loopback driver manually - BlackHole 2ch from existential.audio/blackhole is the recommended free option - and re-run ./install.sh.

Linux users: a Python CLI in linux/ applies the same AutoEQ presets system-wide via PipeWire's filter-chain - run earshot-linux doctor to check your stack, then earshot-linux headphone "HD 600" to download + apply a preset from the bundled catalog.

Uninstall: rm -rf /Applications/Earshot.app - presets stay in ~/Library/Application Support/Earshot/.

What's new in 1.3.0: works with any 2-channel virtual loopback - BlackHole 2ch, VB-Cable, Soundflower (2ch), or Loopback Audio - whichever you already have installed. Modifier-key hint strip below the frequency axis (⇧ lock Hz, ⌥ lock dB, scroll Q, dbl reset, click add).

Ableton Lives

Automatic versioning, encrypted Google Drive backup, and crash recovery for Ableton Live projects on macOS. Every .als save is captured within 30 seconds and stored as a timestamped snapshot; finished audio exports (.wav .aiff .mp3 .flac) are mirrored too. Tiered retention keeps storage small (24h all / hourly to 30d / daily to 6mo / weekly to 1yr / delete). Optional encrypted nightly sync to Google Drive via rclone crypt - Google sees only opaque blobs, no filenames. When Ableton crashes, the closest preceding version is automatically pinned. Right-click any .als in Finder to restore. Native menubar app with live progress bars, sync status and one-click "Sync now". Hard storage caps so the cloud account is never at risk.

Set Memory

A native macOS app for DJs that turns every CDJ-export USB into a searchable, deduped library and auto-suggests playlists worth making. Plug a USB in, the app launches and ingests automatically; a pure-Python .pdb parser handles modern CDJ exports and SQLCipher handles legacy master.db exports. Tracks are collapsed via a normalised (title, artist) key so the same file on two USBs counts once, with cross-USB plays summed. Six suggestion algorithms (forgotten favourites, buy-regret pack, prep audit, co-occurrence cliques, seed-and-companions, Camelot key chains, BPM warm-up-to-peak-to-cooldown arcs) run across every drive ever synced; one click on any suggestion writes it as a playlist into your Mac rekordbox library (backed up first). Right-click any track to Play, Reveal in Finder, or copy metadata. All on-machine, no cloud.

Marquee

A Stremio add-on that replaces the homepage with curated catalog rows that adapt to what you watch. Every detail-page open and every play press is logged to a per-user attention rollup with session clustering, completion ratios, and recency decay; ranking shifts on the next refresh. Library pairing uses Stremio's own four-character code at link.stremio.com: scan the QR, confirm on a phone, your library and watch state land in seconds, and the auth key is discarded after one-shot ingest. Optional Letterboxd public RSS and Last.fm scrobble mood inference, plus zero-click context from weather, time-of-day, lunar phase, and upcoming holidays. Plays nicely with the standard Stremio source pipeline: pick a tile and the usual Torrentio / Real-Debrid / etc. source-selection screen opens unchanged.

Install

End users will eventually install Marquee in one step by pasting its manifest URL into Stremio's add-on search; once submitted to the public add-on registry, no setup or keys will be required. The instructions below are for self-hosting against your own free Cloudflare Workers account.

Download marquee.zip

cd ~/Downloads/marquee

You'll be prompted for an operator-side TMDB v4 read token and a public Trakt client ID (both free from themoviedb.org and trakt.tv). MDBList is optional and unlocks the Beloved bombs row. Uninstall: remove the add-on from Stremio. Local D1 state lives in .wrangler/state/; delete the folder to wipe.

macOS SwiftUI

Jury

Weekly cleanup digest and always-active filesystem monitor for macOS. Scans Documents and Downloads, groups duplicate-variant files (UUID, integer, and (n) suffixes) into clusters, and auto-deletes safe files like .DS_Store, lock files, and partial downloads after an lsof safety check. Protected document types (.docx, .xlsx, .pdf, .pages, .numbers, .key) are never auto-deleted - they're surfaced in a Markdown digest at ~/Documents/cleanup-digest.md with paste-ready Trash commands. A menubar app shows current quarantine, expiring items, and one-click undo; removed files spend 30 days in quarantine before purge.

LittleDia

Floating mini-browser for macOS. ⌘E from any app opens a small window where you type a URL or search; if your clipboard already has a URL it's pre-filled. Inspired by Arc's Little Arc, adapted for Dia but works with Chrome, Safari, Firefox, Brave, and most others. History pulls from whichever browsers you have installed, ranked by frecency, with Google autocomplete on top. ⌘O hands the current page off to a full browser with profile selection; ⌘⇧L adds it to a built-in reading list. Includes Dark Reader integration with per-site toggle, image hover preview, reader mode, find-in-page, a QR-code panel, and userscript support.
