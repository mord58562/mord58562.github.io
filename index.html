A to E

A practice MCQ bank for the final-year Australian MD student. About 830 single-best-answer clinical reasoning questions across paediatrics, obstetrics & gynaecology, psychiatry, and adult medicine. Every option is cited inline against a free Australian clinical reference so any claim is verifiable, and questions are calibrated to test the reasoning steps a candidate has to take rather than to be solvable by spotting a keyword in the stem. The site is a static frontend backed by a Cloudflare Worker; guest mode keeps progress on the device for visitors who don't want an account, while signed-in users see what percentage of other users picked each option after they submit, plus a stats panel with first-time accuracy and per-discipline breakdowns. Authors can paste new questions via a self-contained prompt that works in any free LLM (no API key required), audit and promote them through an in-app dashboard, or run a scheduled cloud agent that generates a fresh 15-20 question batch up to 15 times a day, weighted toward harder difficulty tiers.

Cloudflare Workers · D1 · GitHub Pages
mord58562.github.io/a-to-e ↗ (live, guest mode - no signup) github.com/mord58562/a-to-e ↗
Install

The frontend is a static site - clone or download the zip, open index.html in a browser, and you have the whole bank locally. The Cloudflare Worker piece is only needed if you want accounts + social stats + remote question generation.

Download source zip

Live site: mord58562.github.io/a-to-e (guest mode, no signup required).

Run the worker yourself (optional, gives you accounts + stats + batch publishing):

brew install cloudflare-wrangler
cd cloudflare-worker
wrangler login
wrangler d1 create a-to-e               # paste the printed database_id into wrangler.toml
wrangler d1 execute a-to-e --file=schema.sql --remote
wrangler secret put GITHUB_TOKEN        # fine-grained PAT scoped to your fork, Contents R/W
wrangler secret put ROUTINE_TOKEN       # any random string; required for /commit-batch
wrangler deploy

Then set WORKER_URL in assets/app.js to the printed worker URL, commit, push. See cloudflare-worker/DEPLOY.md for the full walkthrough.

Uninstall: wrangler delete a-to-e-inbox + wrangler d1 delete a-to-e on the worker side; remove the GitHub repo on the frontend side.

Earshot

A menubar parametric EQ for macOS system audio, routed to any output device you pick. Up to 24 bands rendered as draggable dots on the frequency response - drag to set frequency and gain, Cmd-Z to undo. Live editing without dropouts; solo a band to hear exactly what one filter is doing. Auto-preamp parks peaks just under clipping and only ever attenuates. Save named EQ presets; import and export AutoEq ParametricEQ.txt, or search the built-in catalog of ~2000 oratory1990 and Crinacle measurements and load one as a preset. One-click speakers passthrough for when you yank headphones and don't want to dig through Sound preferences.

What's new in 1.2.0: system-output hand-off - picking a different output in the macOS Sound menu / Control Center / Bluetooth wake disengages EQ and lets audio flow straight through; re-selecting BlackHole 2ch as the system output re-engages EQ with the same routing as before, no menubar visit required.

What's new in 1.1.0: menubar glyph now has off / active / bypass states; click empty curve area spawns a band, scroll wheel adjusts Q, drag readout follows the cursor with monospaced figures; right-click a band → Edit values… opens a numeric inspector; Settings window (⌘,) and About panel; first-run sheet walks through BlackHole and microphone permission. Modifier-key hint strip below the frequency axis (⇧ lock Hz, ⌥ lock dB, scroll Q, dbl reset, click add).

Ableton Lives

Automatic versioning, encrypted Google Drive backup, and crash recovery for Ableton Live projects on macOS. Every .als save is captured within 30 seconds and stored as a timestamped snapshot; finished audio exports (.wav .aiff .mp3 .flac) are mirrored too. Tiered retention keeps storage small (24h all / hourly to 30d / daily to 6mo / weekly to 1yr / delete). Optional encrypted nightly sync to Google Drive via rclone crypt - Google sees only opaque blobs, no filenames. When Ableton crashes, the closest preceding version is automatically pinned. Right-click any .als in Finder to restore. Native menubar app with live progress bars, sync status and one-click "Sync now". Hard storage caps so the cloud account is never at risk.

Marquee

A Stremio add-on that replaces the homepage with curated catalog rows that adapt to what you watch. Every detail-page open and every play press is logged to a per-user attention rollup with session clustering, completion ratios, and recency decay; ranking shifts on the next refresh. Library pairing uses Stremio's own four-character code at link.stremio.com: scan the QR, confirm on a phone, your library and watch state land in seconds, and the auth key is discarded after one-shot ingest. Optional Letterboxd public RSS and Last.fm scrobble mood inference, plus zero-click context from weather, time-of-day, lunar phase, and upcoming holidays. Plays nicely with the standard Stremio source pipeline: pick a tile and the usual Torrentio / Real-Debrid / etc. source-selection screen opens unchanged.

Jury

Weekly cleanup digest and always-active filesystem monitor for macOS. Scans Documents and Downloads, groups duplicate-variant files (UUID, integer, and (n) suffixes) into clusters, and auto-deletes safe files like .DS_Store, lock files, and partial downloads after an lsof safety check. Protected document types (.docx, .xlsx, .pdf, .pages, .numbers, .key) are never auto-deleted - they're surfaced in a Markdown digest at ~/Documents/cleanup-digest.md with paste-ready Trash commands. A menubar app shows current quarantine, expiring items, and one-click undo; removed files spend 30 days in quarantine before purge.

Set Memory

A mount-driven analyser for the rekordbox session log on a DJ USB. Every time you plug in a rekordbox drive, Set Memory reads the encrypted master.db via SQLCipher, accumulates every djmdHistory session into a local state.db, and surfaces two things a digital DJ tends to lose track of: tracks played often but not touched in months, and tracks that have been in the library a while but have never appeared in any session. Volumes are discovered, not configured - it walks /Volumes/* looking for the PIONEER/Master/master.db + PIONEER/rekordbox/ shape, so reformatting, renaming, or swapping drives doesn't break sync, and multiple drives plugged in at once all process in the same run. WAL-aware atomic snapshot with retry; deterministic per-session fingerprinting so re-mounts and mirrored drives never double-count. All on-machine - no cloud, no uploads, no audio analysis.

launchd · pyrekordbox · SQLCipher
github.com/mord58562/set-memory ↗
Install

Requirements: macOS 13 Ventura or later, Homebrew, miniconda3 at ~/miniconda3/. The installer verifies the toolchain, builds the launchd agent, and runs an end-to-end smoke test against whatever drive is currently mounted (if any).

Download set-memory.zip 
# one-time, skip if already installed
brew install sqlcipher
brew install --cask miniconda

cd ~/Downloads/set-memory
~/miniconda3/bin/pip install pyrekordbox==0.4.4

Plug any rekordbox USB into the Mac and the agent fires automatically: digest at ~/Downloads/set-memory/digest.md plus a macOS notification. Non-rekordbox mounts are ignored silently. config.json only holds analysis thresholds (no per-drive setup needed).

Uninstall: bash scripts/uninstall.sh - removes the launchd agent and leaves state.db, digest.md, and logs/ in place. Delete them manually for a clean slate.
